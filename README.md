# بوصلة جنى 🧭

موقع تدريبي باللغة العربية لاختبار شهادة **الخدمات المصرفية للأفراد**، مبني على كتاب المنهج الرسمي (`finalRetailBanking20231207.pdf`) وعلى نمط أسئلة الاختبار الحقيقي.

> Abdullah Trusts you 🤍

## المزايا
- **699 سؤالاً** تغطي الفصول العشرة من الكتاب كاملة، ولكل سؤال شرح ومرجع (الفصل والقسم ورقم الصفحة).
- **اختبار شامل** من 100 سؤال بنفس توزيع الاختبار الحقيقي على الفصول، في 100 دقيقة.
- **اختبار حسب الفصل**: فصل واحد أو عدة فصول، بوضع «اختبار» أو «تدريب فوري».
- أسئلة «اختاري إجابتين/ثلاث» مثل الاختبار الحقيقي.
- ترتيب الأسئلة والخيارات **عشوائي في كل محاولة**.
- درجة النجاح **75%** (أصعب من الاختبار الحقيقي 65%).
- **بنك الأخطاء**: كل سؤال خاطئ يبقى حتى تُجاب عليه إجابتان صحيحتان متتاليتان.
- سجل النتائج، ومستوى الإتقان لكل فصل، ونسخة احتياطية (تنزيل/استعادة).
- صفحة نصائح: أشهر الفخاخ، وجدول الأرقام المهمة، وخطة مذاكرة.
- يعمل على الجوال ويدعم الوضع الليلي. لا يحتاج خادماً ولا قاعدة بيانات؛ التقدم محفوظ في متصفح الجهاز (`localStorage`).

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشره على GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.

## البنية
```
index.html      الصفحة
style.css       التصميم
app.js          منطق الاختبارات والتخزين
data/meta.js    الفصول والنصائح وجدول الأرقام
data/chN.js     أسئلة الفصل N
```
صيغة السؤال في `data/chN.js`:
`[نص السؤال, [الخيارات...], رقم الإجابة الصحيحة أو مصفوفة أرقام, الشرح, المرجع]`
(تُكتب الإجابة الصحيحة أولاً، والتطبيق يخلط الخيارات تلقائياً).
