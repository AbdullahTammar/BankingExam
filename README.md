# بوصلة جنى 🧭

موقع تدريبي باللغة العربية لشهادتين، كل واحدة في قسم مستقل تختاره جنى من الصفحة الأولى:

1. **الخدمات المصرفية للأفراد** — مبني على كتاب المنهج الرسمي وعلى نمط أسئلة الاختبار الحقيقي.
2. **المستشار الائتماني** — مبني على كتاب `CreditAdvisor6_09112023.pdf` (الإصدار الرابع) وعلى أسئلة المحاولة الأولى والاختبار التجريبي.

لكل قسم اختباراته وبنك أخطائه وسجله الخاص (لا يختلط التقدم بين القسمين).

> Abdullah Trusts you 🤍

## قسم المستشار الائتماني
- **544 سؤالاً** تغطي الفصول الخمسة، لكل سؤال: الإجابة الصحيحة، ولماذا، و**سيناريو بسيط**، ورقم **الصفحة** في الكتاب.
- **اختبار شامل** 100 سؤال بنفس توزيع الاختبار الحقيقي (40 / 13 / 13 / 14 / 20)، و**6 نماذج اختبارات ثابتة**.
- **اختبار حسب الفصل** بوضع الاختبار أو التدريب الفوري.
- **السيناريوهات (52)**: كل تعريف بثلاث خطوات: ببساطة ← قصة من الواقع ← فخ الاختبار، مع جداول مقارنة (مثل المرابحة × الإجارة).
- **بنك الأسئلة والإجابات** مع بحث بالكلمة وفلترة حسب الفصل.
- **الاختبار السابق**: 29 سؤالاً من المحاولة الأولى في الاختبار الحقيقي + 37 من الاختبار التجريبي، والإجابات المخالفة للكتاب مصححة وعليها ⚠️.
- نصائح وأرقام لا تُنسى (مع الصفحات) وخطة مذاكرة خاصة بالكتاب.

## مزايا قسم الخدمات المصرفية للأفراد
- **699 سؤالاً** تغطي الفصول العشرة من الكتاب كاملة، ولكل سؤال شرح ومرجع (الفصل والقسم ورقم الصفحة).
- **اختبار شامل** من 100 سؤال بنفس توزيع الاختبار الحقيقي على الفصول، في 100 دقيقة.
- **اختبار حسب الفصل**: فصل واحد أو عدة فصول، بوضع «اختبار» أو «تدريب فوري».
- أسئلة «اختاري إجابتين/ثلاث» مثل الاختبار الحقيقي.
- ترتيب الأسئلة والخيارات **عشوائي في كل محاولة**.
- درجة النجاح **75%** (أصعب من الاختبار الحقيقي 65%).
- **بنك الأخطاء**: كل سؤال خاطئ يبقى حتى تُجاب عليه إجابتان صحيحتان متتاليتان.
- سجل النتائج، ومستوى الإتقان لكل فصل، ونسخة احتياطية (تنزيل/استعادة).
- صفحة نصائح: أشهر الفخاخ، وجدول الأرقام المهمة، وخطة مذاكرة.
- يعمل على الجوال ويدعم الوضع الليلي. لا يحتاج خادماً ولا قاعدة بيانات؛ التقدم محفوظ في متصفح الجهاز (`localStorage`).

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشره على GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.

## البنية
```
index.html      الصفحة
style.css       التصميم
app.js          منطق الاختبارات والتخزين
data/meta.js    الفصول والنصائح وجدول الأرقام
data/chN.js     أسئلة الفصل N
data/credit/    قسم المستشار الائتماني:
  meta.js       الفصول والنصائح والأرقام والفخاخ
  chN.js        أسئلة الفصل N
  oldexam.js    أسئلة الاختبار السابق والتجريبي
  scenarios.js  السيناريوهات
```
صيغة السؤال في `data/chN.js`:
`[نص السؤال, [الخيارات...], رقم الإجابة الصحيحة أو مصفوفة أرقام, الشرح, المرجع]`
(تُكتب الإجابة الصحيحة أولاً، والتطبيق يخلط الخيارات تلقائياً).

صيغة السؤال في `data/credit/chN.js` تضيف حقلاً سادساً للسيناريو:
`[نص السؤال, [الخيارات...], الإجابة, لماذا, المرجع والصفحة, سيناريو بسيط]`
